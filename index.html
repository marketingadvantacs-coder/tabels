Как пользоваться и не потерять брони

1. В разделе «Столы» выберите день, начало и длительность. Нажмите на стол, введите фамилию и сохраните.

2. В разделе «Встречи» можно изменить стол, перенести время и отменить бронь. Соседние интервалы, например 10:00–10:30 и 10:30–11:00, разрешены.

3. Скачивайте резервную копию в конце дня. Убедитесь, что файл появился в «Загрузках», или отправьте его себе через кнопку «Поделиться копией».

4. Очистка данных браузера, удаление браузера или смена телефона могут удалить базу. Восстановить ее можно из JSON-копии. При восстановлении текущие записи заменяются; прежняя база остается доступна кнопкой возврата.

5. Добавьте ссылку на главный экран через меню браузера. Сохраняйте прежний адрес приложения при обновлении HTML. Для повторного открытия ссылки нужен доступ к GitHub Pages. Уже загруженная страница сохраняет брони без подключения к интернету.

6. Разместите этот файл под именем index.html в GitHub Pages. Google, серверная база и отдельные скрипты не требуются. JavaScript внутри HTML должен быть разрешен браузером.

Если корпоративная система запрещает открывать GitHub Pages или выполнять JavaScript, приложение также не запустится.
